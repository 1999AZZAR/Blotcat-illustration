# Composition Patterns & Originality Rules

## Basic Structure Types

Choose only one structure type; do not mix too many.

### Workflow

Suitable for: Input -> Processing -> Output, content production, AI workflows, automation chains.

How to draw: Input on the left, Blotcat or a strange machine processing in the middle, output on the right, orange arrows indicating the main flow.

### System Partial

Suitable for: Information sources, filters, databases, renderers, agent system components.

How to draw: Draw only 3-5 core modules, with Blotcat participating in one key action.

### Before and After Comparison

Suitable for: Chaos/Order, Manual/Automatic, Scattered/Gathered, Anxiety/Stability.

How to draw: Chaos on the left, stability on the right, orange arrow in the middle. Characters can be more exaggerated.

### Character State

Suitable for: User pain points, creator states, tool overload, information anxiety, from stuck to running.

How to draw: 2-4 small states, each with a short annotation.

### Conceptual Metaphor

Suitable for: Content factories, information warehouses, brain black boxes, workflow machines, automated daily reports.

How to draw: A large strange object or machine, a few inputs, one output. It must be memorable.

### Method Layering

Suitable for: Methodology frameworks, system hierarchies, skill stacks, content system layering.

How to draw: Layers of boxes, not a formal pyramid; Blotcat moving bricks or building nearby.

### Map Route

Suitable for: From idea to launch, user paths, content handoff paths, learning roadmaps.

How to draw: A winding path, a few nodes, Blotcat pulling a string or walking.

### Comic Panels

Suitable for: From failure to success, real processes, rants, before and after use.

How to draw: 2-4 small panels, each panel expressing only one action.

## Original Metaphor Generation Method

Always invent a new metaphor based on the current article; do not copy old images.

### Three Steps

1. Turn an abstract concept into a physical action: stuck, missed, heavy, sort, settle, ferment, open door, fold, unpack, return.
2. Turn a system structure into a low-tech object: broken machine, cardboard box, drawer, water pipe, mailbox, weird dial, scale, well, ladder, strange workstation.
3. Make Blotcat perform the action: not just standing nearby, but stuck in the machine, pulling the wrong wire, guarding the door, carrying, patching, weighing, holding a ladder, recording, or stuffing things into a weird device.

### Usable Object Pool

- Cardboard boxes, drawers, old machines, funnels, scales, mailboxes, doors, wells, ladders, water pipes, yarn balls, gates, turntables, black boxes, hole punchers, pasta makers, clotheslines, strange workstations.
- Select only 1-2 when using; do not overcrowd.

### Blotcat Action Pool

- Pull, carry, stuff, fish out, press, weigh, sew, cut, twist, guard, push, catch, dismantle, mark, recycle.
- The action must serve the core meaning, not just be weird for the sake of being weird.

## Anti-Copy Rules

Do not default to opening or replicating `assets/examples/`. These images are only for style calibration, such as line density, white space, color restraint, and Blotcat's vibe.

Unless the user explicitly says "copy this one / replicate this composition / use this example to modify", do not directly reuse these old compositions:

- Two breakpoints on a conveyor belt
- Blotcat pulling a judgment lever in a content machine
- Blotcat turning into a funnel sorting traffic/trust/conversion
- Blotcat cutting a material fish
- Blotcat pulling a handoff path
- Blotcat pulling three layers of information sources
- Three Blotcats holding megaphones/building bridges/opening doors
- Blotcat stamping a script toolbox
- Blotcat holding a sign looking at a common pitfall path

For similar topics, change to a new metaphor. For example, "handoff path" doesn't necessarily mean drawing a route; it could be Blotcat connecting a content tail to a doorknob; "one fish, many uses" doesn't have to be a fish; it could be Blotcat pressing a ball of paper into several shapes.
