# Prompt Examples

The following prompts can be directly copied into Codex for use.

## Illustration Planning Only

```text
Use $blotcat-illustrations do not generate images yet.
Please analyze where this article is worth illustrating, and output a shot list of about 5 images.
For each image clearly write:
- After which paragraph it is placed
- Theme of the image
- Core meaning
- Structure type
- What Blotcat is doing in the image
- Suggested elements
- Suggested English annotation words

<Paste article>
```

## Article Body Illustration

```text
Use $blotcat-illustrations to generate 4 Blotcat quirky body text illustrations for the following article.
Requirements: 16:9 horizontal, pure white background, black hand-drawn line art, sparse red/orange/blue handwritten English annotations.
Each image should only explain one core structure, no PPT infographics, no cute cartoons.

<Paste article>
```

## Long Article Illustration Strategy

```text
Use $blotcat-illustrations to create an illustration strategy for this long article.
Do not illustrate evenly, pick only cognitive anchors: core judgments, input-output loops, before and after comparisons, common pitfalls, handoff paths.
Default to 6-8 images, output the shot list first, do not generate images.

<Paste article>
```

## Generate One Image for a Single Idea

```text
Use $blotcat-illustrations to generate a 16:9 body text illustration for this viewpoint:

Trust is not shouted out, but paved piece by piece with evidence.

The visual should be quirky but clean, Blotcat must perform the core action.
English annotations at most 5, keep them short.
```

## Workflow Theme

```text
Use $blotcat-illustrations to generate an image for "processing a piece of raw material into three types of content: traffic, trust, and conversion".
Do not draw a formal flowchart, do not copy the old "one fish many uses" example.
Please invent a new low-tech metaphor, let Blotcat participate in the core action.
```

## Edit Image: Remove Title

```text
Use $blotcat-illustrations to help me edit this image.
Remove the "Workflow / Flowchart" title and underline in the top left corner, keep other content unchanged.
Do not add any new text or objects.
```

## Edit Image: Enhance Blotcat's Participation

```text
Use $blotcat-illustrations this image is in the right direction, but Blotcat looks a bit like a decoration.
Please keep the core meaning unchanged, regenerate a version: make Blotcat the person who truly drives the structure to run.
Make the visual a bit weirder, but still pure white, clean, and sparse text.
```

## Generate a Set of Style Samples

```text
Use $blotcat-illustrations to output 5 Blotcat body text illustration effects on different themes.
Themes cover respectively: Information Overload, Product Validation, Content Compound Interest, Solopreneur, Trust Building.
Generate each image separately, do not combine into one.
```
